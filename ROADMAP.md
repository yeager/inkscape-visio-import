# Proposed next improvements

Prioritized follow-up proposals; these are not implemented in this release.

1. Convert only the requested page once native single-page conversion supports binary documents consistently.
2. Offer import of multiple pages using Inkscape page metadata rather than silently discarding all but one page.
3. Add tests against real Inkscape/inkex on supported platforms and both VSDX and binary VSD fixtures.
4. Show conversion diagnostics with the imported document so unsupported elements are visible to users.
